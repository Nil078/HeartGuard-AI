## Stack

Python, scikit-learn, Streamlit, Plotly. Training is offline (`train_model.py`). The app only loads `heart_disease_model.pkl` and `model_metadata.json`.

## Setup & Terminal Execution

For a detailed walkthrough, see the dedicated **[Terminal Execution Guide](RUN_GUIDE.md)**.

Quick start:

```bash
# 1. Activate virtual environment
source ../.venv/bin/activate    # or source .venv/bin/activate

# 2. Verify dependencies
pip install -r requirements.txt

# 3. (Optional) Retrain offline model
python3 train_model.py

# 4. Launch Streamlit UI
streamlit run app.py
```

## Training notes

- Stratified 80/20 split (`random_state=42`) **before** any fitting.
- `ColumnTransformer` + estimator in one `Pipeline` per model. Scalers/encoders are fit on the training fold only.
- Tree-based models are not scaled; logistic regression, SVM, and KNN are.
- Model choice uses a combined test-set score with **recall weighted highest** (screening context), plus ROC-AUC, F1, and accuracy.
- XGBoost is trained if the package imports; otherwise training continues and the omission is recorded in metadata.
